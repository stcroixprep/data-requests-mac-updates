# Data Requests — signed macOS updates

This public repository is reserved for signed Data Requests application releases.

When the update pipeline is configured, it will publish:

- `appcast.xml` — the Sparkle update feed
- `Data-Requests.zip` — the compiled Mac app archive
- `release-notes.txt` — user-facing release notes

This repository must not contain source code, live request records, student data, credentials, or private update-signing keys. The app source lives in the private `stcroixprep/data-requests-mac` repository.

**Status:** Update signing and initial release are not configured yet; there is no downloadable release here yet.
